# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

A library of 754 structured cybersecurity skills for AI agents, following the [agentskills.io](https://agentskills.io) open standard. Each skill encodes a practitioner workflow — step-by-step procedures, real commands, and decision trees — mapped to MITRE ATT&CK, NIST CSF 2.0, MITRE ATLAS, MITRE D3FEND, and NIST AI RMF. This is a content repository, not a software project; there is no build system or test runner.

## Validation

Run the frontmatter validator locally (mirrors the CI check):

```bash
# Validate all SKILL.md frontmatter and check for duplicate names
python3 -c "
import os, re, sys
from collections import Counter
REQUIRED = ['name','description','domain','subdomain','tags','version','author','license']
errors, names = [], []
for root, _, files in os.walk('skills'):
    for f in files:
        if f != 'SKILL.md': continue
        path = os.path.join(root, f)
        content = open(path).read()
        fm = re.match(r'^---\n(.*?)\n---', content, re.DOTALL)
        if not fm: errors.append(f'{path}: missing frontmatter'); continue
        for field in REQUIRED:
            if not re.search(rf'^{field}:', fm.group(1), re.MULTILINE):
                errors.append(f'{path}: missing {field!r}')
        nm = re.search(r'^name:\s*(.+)$', fm.group(1), re.MULTILINE)
        if nm: names.append(nm.group(1).strip().strip('\"'))
dupes = [n for n,c in Counter(names).items() if c>1]
if dupes: errors.append(f'Duplicate names: {dupes}')
[print(e) for e in errors]; sys.exit(bool(errors))
"
```

CI runs this automatically on any PR that touches `skills/**`.

## Skill structure

Every skill lives in `skills/<kebab-case-name>/`:

```
skills/skill-name/
├── SKILL.md              ← required: YAML frontmatter + Markdown body
├── references/
│   ├── standards.md      ← MITRE/NIST framework mappings (optional)
│   └── workflows.md      ← deep technical reference (optional)
├── scripts/
│   └── agent.py          ← working helper script (optional)
└── assets/
    └── template.md       ← report/checklist template (optional)
```

### SKILL.md frontmatter

Required fields: `name`, `description`, `domain`, `subdomain`, `tags`, `version`, `author`, `license`.

Optional framework fields: `mitre_attack` (list of technique IDs), `nist_csf`, `d3fend_techniques`, `atlas_techniques`, `nist_ai_rmf`.

Rules enforced by CI:
- `name` must be kebab-case, 1–64 characters, matching the directory name
- `domain` is always `cybersecurity`
- `subdomain` must be one of the values listed in `CONTRIBUTING.md`
- `license` is `Apache-2.0`

### SKILL.md body sections

Use these section headings in order: `## When to Use`, `## Prerequisites`, `## Workflow` (numbered steps with real commands), `## Key Concepts` (table), `## Tools & Systems`, `## Common Scenarios`, `## Output Format`.

Not all sections are required for every skill — include those that are meaningful for the domain.

## Adding a new skill

1. Create `skills/<your-skill-name>/SKILL.md` with the required frontmatter and Markdown body.
2. Submit a PR with the title `Add skill: your-skill-name`.
3. Supporting files (`references/`, `scripts/`, `assets/`) are optional but improve skill quality.

Domains with the fewest skills (most needed): Deception Technology (2), Compliance & Governance (5), Ransomware Defense (7).

## Repository layout beyond `skills/`

- `index.json` — auto-generated skill index (do not edit manually; regenerated by `update-index.yml` on every push to main)
- `mappings/` — framework coverage summaries (MITRE ATT&CK, NIST CSF, OWASP)
- `.github/workflows/validate-skills.yml` — frontmatter validation CI
- `.github/workflows/update-index.yml` — index regeneration CI
- `ATTACK_COVERAGE.md` — ATT&CK tactic/technique coverage overview
